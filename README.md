# Test Assignment

## Описание

Тестовое задание - Unity‑проект, демонстрирующий работу с UI, анимациями и асинхронной загрузкой изображений.

## Технологии

* Unity 2022.3
* URP
* UniTask
* PrimeTween
* Zenject

## Запуск проекта

1. Открыть проект в Unity 2022.3.x.
2. Открыть сцену `Main`.
3. Нажать **Play**.
